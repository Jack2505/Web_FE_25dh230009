# Nova Store — Website bán hàng Front-end

**Sinh viên:** Hoàng Nguyễn Quốc Duy  
**MSSV:** 25dh230009  
**Lớp:** SE2505

## Giới thiệu
Dự án website bán hàng front-end được xây dựng bằng HTML, CSS và JavaScript thuần. Giao diện minh họa các chức năng duyệt sản phẩm, lọc danh mục, tìm kiếm và quản lý giỏ hàng.

## Cấu trúc dự án
- `index.html`: Trang chủ, banner, danh mục, danh sách sản phẩm và tìm kiếm.
- `product.html`: Trang chi tiết sản phẩm.
- `cart.html`: Trang giỏ hàng.
- `css/style.css`: Giao diện và bố cục responsive.
- `js/data.js`: Dữ liệu sản phẩm, định dạng giá và các hàm giỏ hàng.
- `js/app.js`: Lọc danh mục, tìm kiếm và thêm sản phẩm vào giỏ.
- `js/product.js`: Hiển thị trang chi tiết sản phẩm.
- `js/cart.js`: Cập nhật số lượng, xóa sản phẩm và tính tổng tiền.

## Cách chạy
1. Tải hoặc giải nén dự án.
2. Mở thư mục `Web_FE_Development` bằng Visual Studio Code.
3. Mở `index.html` trong trình duyệt hoặc chạy bằng tiện ích Live Server.

## Chức năng chính
- Xem danh sách sản phẩm và danh mục.
- Tìm kiếm và lọc sản phẩm.
- Xem chi tiết sản phẩm.
- Thêm sản phẩm vào giỏ hàng.
- Thay đổi số lượng, xóa sản phẩm và tính tổng tiền.
- Lưu giỏ hàng bằng `localStorage` trên trình duyệt.

## Giới hạn
Dữ liệu sản phẩm và giá mang tính minh họa. Chức năng đặt hàng/đăng ký chưa kết nối máy chủ, cơ sở dữ liệu hoặc cổng thanh toán.
